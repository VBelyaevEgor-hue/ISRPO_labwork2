# geometric_lib

## Общее описание решения:
Решение содержит в себе набор функций на языке Python для вычисления площади и периметра четырех геометрических фигур - кргуа, прямоугольника, квадрата и треугольника

## Описание функций

### Круг
Функции подсчета площади и периметра
#### `area(r)`
Возвращает площадь круга.
* **Параметры:**
  * `r` (float): Радиус круга.
* **Возвращает:**
  * `area` (float): Площадь круга.

**Пример вызова:**
```python
import math
def area(r):
    return math.pi * r * r

print(f"Площадь круга: {area(5)}")
```

#### `perimeter(r)`
Возвращает периметр круга.
* **Параметры:**
  * `r` (float): Радиус круга.
* **Возвращает:**
  * `perimeter` (float): Периметр круга.

**Пример вызова:**
```python
import math
def perimeter(r):
    return 2 * math.pi * r

print(f"Периметр круга: {perimeter(5)}")
```


### Прямоугольник
Функции подсчета площади и периметра
#### `area(a, b)`
Возвращает площадь прямоугольника.
* **Параметры:**
  * `a` (float): Длина прямоугольника.
  * `b` (float): Ширина прямоугольника.
* **Возвращает:**
  * `area` (float): Площадь прямоугольника.

**Пример вызова:**
```python
def area(a, b):
    return a * b

print(f"Площадь прямоугольника: {area(4, 6)}")
```
#### `perimeter(a, b)`
Возвращает периметр прямоугольника.

* **Параметры:**
  * `a` (float): Длина прямоугольника.
  * `b` (float): Ширина прямоугольника.
* **Возвращает:**
  * `perimeter` (float): Периметр прямоугольника.

**Пример вызова:**
```python
def perimeter(a, b):
    return 2 * (a + b)
```


### Квадрат

* **Параметры:**

* **Возвращает:**
  * `area` (float): Площадь квадрата.

**Пример вызова:**
```python
def area(a):

print(f"Площадь квадрата: {area(5)}")
```

#### `perimeter(a)`
Возвращает периметр квадрата.
* **Параметры:**
  * `a` (float): Длина стороны квадрата.
* **Возвращает:**
  * `perimeter` (float): Периметр квадрата.

**Пример вызова:**
```python
def perimeter(a):
    return 4 * a

print(f"Периметр квадрата: {perimeter(5)}")
```


### Треугольник
Функции подсчета площади и периметра
#### `area(a, h)`
Возвращает площадь треугольника.
* **Параметры:**
  * `a` (float): Длина основания треугольника.
  * `h` (float): Высота треугольника.
* **Возвращает:**
  * `area` (float): Площадь треугольника.

**Пример вызова:**
```python
def area(a, h):
    return a * h / 2

print(f"Площадь треугольника: {area(6, 4)}")
```

#### `perimeter(a, b, c)`
Возвращает периметр треугольника.
* **Параметры:**
  * `a` (float): Длина первой стороны треугольника.
  * `b` (float): Длина второй стороны треугольника.
  * `c` (float): Длина третьей стороны треугольника.
* **Возвращает:**
  * `perimeter` (float): Периметр треугольника.

**Пример вызова:**
```python
def perimeter(a, b, c):
    return a + b + c

print(f"Периметр треугольника: {perimeter(3, 4, 5)}")
```
